# Item Model Spawner 
Adds a menu that lets you spawn an item display with any item model even those from resource packs.

Works in single- and multiplayer (with OP permissions)

Default Keybind: V

Toggle: All or Resource Pack

Dye Color: enter a hex color (e.g. `FF0000` or `#FF0000`) in the dye color box before clicking a model to spawn it with a `minecraft:dyed_color` component. Leave it empty for no dye.
